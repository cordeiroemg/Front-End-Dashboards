How to Use the Pedigree Simulation Tool
Step-by-Step Instructions
  1. Enter a Pedigree in JSON Format
    Use the provided textarea to define your family structure.
    Each individual must be represented by a unique ID and include an optional "parents" array.
    Example: 
    {
  "A": {"parents": null},
  "B": {"parents": null},
  "C": {"parents": ["A", "B"]}
}
  2. Choose the Number of Loci
    Use the numeric input to select how many genetic loci to simulate (default: 10,000).
  3. Click "Simulate"
    This will calculate inbreeding and relatedness values.
    You will see:
    • A summary table of coefficients.
    • A heatmap of genetic relatedness (rᵢⱼ).
    • A pedigree tree diagram showing ancestry.
Orientation of the Pedigree Tree

The tree is drawn using a computational layout:

  • Most recent individual appears at the top.
  • Parents and ancestors are placed below their children.

Note: This is the reverse of traditional family trees, but it reflects the recursive structure used in simulation.

Tips for Valid JSON Pedigrees
  • Each individual must have zero or two parents.
  • Parents must exist in the JSON before being referenced.
  • No cycles — an individual cannot be their own ancestor.
  • Use a strictly hierarchical structure without loops.

If the JSON is invalid, the simulation will not run. Please review your input and try again.
